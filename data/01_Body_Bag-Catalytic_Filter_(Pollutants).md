## Cable Networks

When placing cables with Cable Coil you create cable networks. These contain volatile memory that can be read or written to using a Integrated Circuit (IC10). This includes a variety of special logic variables such as Channel0 through to Channel7. The networks also have readable memory, which contains a list of all the data devices on the network, and can be used with GET to find the ReferenceId for that device. To find out the current quantity of devices in the stack, use the StackSize variable on the network, as the network adjusts its stack size dynamically based on devices within it. Cable Networks are volatile memory, and will change both their order, contents, and data whenever the network changes - so you may need to constantly poll and update the information. To access this, use extra notation on your device references such as d0:1 to access network 1 off the provided device. To find out the connection number, check the stationpedia page for that device for the number under the connections section.

- **Key:** CableNetworkPage
